# Experiment B — pre-registered before a single call was made

**2026-09-02.** Experiment A failed: asked for a whole workflow step, Nemotron scored 10/20 against
a threshold of 14. **That verdict stands and is not reopened by anything here.**

Half of A's failures were not wrong logic. They were malformed YAML: lines at column 0 inside a
block scalar, stray heredoc terminators. B asks whether that formatting burden was the binding
constraint.

## The single variable that changes

**A:** the model returns a complete GitHub Actions step, YAML included.
**B:** the model returns **only the shell body**. Deterministic code indents it and wraps it in
`run: |`.

Everything else is byte-identical: the same 20 rules, the same 40 frozen fixtures, the same
execution contract, the same scoring, `temperature 0`, the same `max_tokens`, the same harness.

## Why this is a fix to reality, not a widened gate

No sane implementation of Elenchos would ask a model to emit YAML. The model supplies the check's
logic; deterministic code emits the workflow around it, because that part has one correct answer and
never needs a model. **B tests the architecture we would actually build.** A tested an architecture
we would not.

That is the whole justification, and it is the only one. If B passes, what it licenses is a
**redesign** in which the model never writes YAML — not a retroactive pass for A.

## What is fixed before the first call

1. **The threshold does not move: `>= 14/20` AND `>= 6` above the template.** Same bar, easier
   interface. It is not relaxed to reward the change.
2. **The wrapper is dumb and deterministic.** It strips markdown fences, indents every line by four
   spaces, and puts it under `run: |`. It does **not** repair heredocs, quoting, or logic. Anything
   beyond indentation is the model's own work.
3. **Three draws again**, because the endpoint is not deterministic at `temperature 0`. All three
   reported, whatever they say. No fourth.
4. **The template and the oracle are re-run unchanged**, to prove the interface change did not move
   the baseline. The template's body is generated by code, so its 2/20 should be unchanged; if it
   moves, the comparison is contaminated and B is void.
5. If the model returns YAML anyway, despite being asked for shell, that is **its** failure and is
   scored as such. The wrapper does not detect and unwrap it.

## Result

    Draw 1   16 / 20
    Draw 2   14 / 20
    Draw 3   14 / 20      minimum 14, mean 14.7, gap over the template 12

    Experiment A, for comparison, same rules and fixtures:  10 / 13 / 14

    Threshold >= 14 AND >= 6 over template:  MET ON ALL THREE DRAWS.

    Baselines re-run unchanged, as condition 4 required:  oracle 20/20, template 2/20.
    The interface change did not move the baseline, so the comparison is not contaminated.

**The formatting burden was the binding constraint.** In A, five of twenty answers were not valid
YAML. In B, **zero of sixty** failed to parse, and not one response returned YAML when asked for
shell. The model was never bad at writing the check; it was bad at writing the file around it.

## What this does and does not establish

**Does:** with the wrapper deterministic, Nemotron turns prose rules into checks that actually fire,
at 14 to 16 of 20, against a lexical template's 2. The bar was set before any of this ran and was
not moved to accommodate it.

**Does not:** rescue Experiment A. The originally designed entry, where the model emits the whole
step, failed its gate and stays failed. What B licenses is a **redesign**: the model supplies the
check's logic and never touches YAML.

**And the margin is thin, which is stated rather than smoothed.** Two of three draws landed exactly
on 14. Two rules never pass in any draw:

- `r14`, and it is a genuine weakness. The model greps for the literal `secret-scanning` in all
  three draws, so it misses a step named "Secret scan" that runs `gitleaks`. Too narrow a match, the
  same failure mode the template has.
- `r20`, which is **our** fixture defect, not the model's: `test/` against `tests/`, disclosed in
  Experiment A and deliberately never repaired. Crediting it would put B at 15 to 17.
